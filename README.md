This is a complete port of the original CreateCafe mod from Forge to NeoForge 1.21.1.

Summary of major changes:
- Updated build. gradle and mods. toml for NeoForge 1.21.1
- Migrated from Minecraft Forge API to NeoForge API
- Updated registration system to use new NeoForge registries
- Adapted to Minecraft 1.21.1 mapping changes
- Fixed incompatible method signatures and removed deprecated APIs
- Resolved any package relocation issues

# CreateCafe

Addon to the Create mod for Minecraft 1.18+

Adds Boba Tea and Iced Coffee drinks that give the player potion effects
